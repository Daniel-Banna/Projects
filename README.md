# Java Projekte

Dieses Repository enthält mehrere Java-Projekte, die im Rahmen von eigenständigem Lernen und praktischer Übung entwickelt wurden.

## Inhalte
- Konsolenanwendungen (z. B. Geldautomat, Smart-Home-Simulation)
- Fokus auf objektorientierte Programmierung (OOP)
- Saubere Code-Struktur und verständliche Implementierung

## Technologien
- Java
- Objektorientierte Programmierung (OOP)
- Git & GitHub

## Ziel
Ziel dieses Repositories ist es, praktische Erfahrung in der Java-Softwareentwicklung zu sammeln, Problemlösungen umzusetzen und Code kontinuierlich zu verbessern.
